# Sofia — The Global Luxury Trading Platform

The all-in-one platform for professional watch dealers — with verified market intelligence, a trusted dealer network, and seamless trading tools.

## Features
- **Pixel-Perfect Luxury Hero Viewport**: Handcrafted layout matching the official Sofia trading platform aesthetic.
- **Responsive Widescreen & Desktop Layout**: Fluid typography and layout scaling across all modern screen resolutions.
- **Photographic Studio Imagery**: Showcasing the Rolex Cosmograph Daytona chronograph on a veined marble pedestal.
- **Interactive Navigation & VIP Dealer Access**: Full modal application system with instant feedback.
- **Built-In Visual Pixel Comparison**: Press `O` or use the on-screen toggle to compare against the reference layout.

## Getting Started
Open `index.html` directly in any web browser, or serve with Node.js:
```bash
node server.js
```
Then visit `http://localhost:3000`.
